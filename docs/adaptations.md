# 阶段二来源与演示新增适配

本文记录阶段二基线，以下“阶段三将/尚未实现”为当时状态。阶段三当前实现与新增迁移见 `phase3-adaptations.md`，实际验证见 `phase3-acceptance.md`。

保留源代码：身份/权限/库存与异常工作流的 18 张表；按类白名单抽取，外键共 28 个且目标闭合。未抽取移动端、审批、CRM、财务、背景全业务扫描或修复写入模型。

源模型字段与约束保留。JSONB 增加 SQLite 方言适配，PostgreSQL 仍使用 JSONB。ORM 注册、独立 Base 与最小配置为新适配；原业务聚合导入未复制。初始 Alembic 迁移是新生成并冻结的完整 18 表迁移，不依赖原 revision 链。

`inventory_agent_service.py` 保留原负库存/锁定库存判定、案件指纹、证据版本和最新已提交批次选择；`evidence_contract.py` 从原诊断服务按符号依赖闭包抽取 Schema、证据投影、脱敏、合法引用集合与危险建议检查。

`reference/*.py.txt` 是有来源行号的非运行源码片段，只保留领取/心跳/所有权验证/预算/结果回写、授权查询/建任务、诊断接口与 Provider 契约路径。片段缺少原聚合依赖和上下文，不应 import 或冒充可运行 Worker。阶段三将逐项解耦，保留所有权/证据复核语义。

新增：demo 安全配置、固定种子数据/账号/范围、新 Mock 适配、初始化与数据验证脚本、本地 Compose。数据范围 JSON 使用展示版 warehouse 约定，权限如何映射到 API 留在阶段三；这是展示新增约定，不声称已保留原完整权限服务。

阶段一规划中的 API/main、前端、后台 Worker 与 PostgreSQL 租约并发测试尚未实现；全局编排器、API dependencies、权限服务原文件不机械复制。它们不属于阶段二数据层已验证范围。
