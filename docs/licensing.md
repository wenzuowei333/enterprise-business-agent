# 来源与发布方式

所选上游快照中没有 LICENSE、COPYING 或 NOTICE 文件。源码位于用户控制的私有仓库，这只能证明访问来源，不能替代所有模块、工作成果及素材的权属证明。

当前选择为**本地/私有展示候选，保留原有权利，不额外授予开源再分发许可**。没有给原代码套用 MIT、Apache 等新许可证。后续公开之前，应核实原业务代码、工作成果的对外展示权限，再确定公开代码或仅展示设计说明/录屏的范围；此项留在发布清单中，不把扫描通过写成权属已确认。

第三方依赖仍遵循各自许可证。`THIRD_PARTY_NOTICES.md` 和 `docs/dependency-licenses.json` 记录本次锁定依赖的实际安装元数据，保留许可证正文索引和摘要；未将依赖源码或安装环境打包进候选。元数据清单是来源检查记录，不是自动授予许可或法律判断。

参考素材、Mock 占位输出与登录插图的来源沿用合成素材说明。没有复制原业务图片、Logo 或第三方摄影素材。
