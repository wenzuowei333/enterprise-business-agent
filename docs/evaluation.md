## 运行测试

需要 Docker、Python 3.12、uv，测试库端口未被其他实例使用。测试会重建专用测试库，不指向演示数据库或生产库：

```sh
uv venv --python 3.12
uv pip install -r backend/requirements-dev.lock playwright==1.58.0
.venv/bin/python demo/run_checks.py
```

浏览器依赖安装后，向已启动的本机演示执行 `.venv/bin/python demo/browser_smoke.py`。该命令会创建真实演示任务，不只是打开页面。

空卷复现与隔离运行使用 `ci/run.py --fresh-data-check`，完整依赖/浏览器安装、独立项目名和端口前提见 [阶段五入口](runbook.md#阶段五验收入口)。它要求专用项目尚不存在；会检查种子重复和新卷重建摘要一致，再运行全部测试。依赖安装需要软件源网络；运行期使用 Mock 和本地服务。

实测环境：macOS 26.6.2 arm64、Python 3.12.12（主机）/3.12.16（容器）、PostgreSQL 16.15、Docker 29.2.0、Compose 5.0.2、Chrome 156.0.8078.80、Playwright Python 1.58.0。构建允许利用镜像层缓存；没有对首次无缓存安装计时。
