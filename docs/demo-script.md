# 实际录屏分镜

视频时长 **78.04 秒**，1440×1000、25 fps、H.264 MP4、无音轨。浏览器真实操作，未加速、未拼接或伪造任务状态；转码做兼容压缩和移除输入元数据。没有裁掉业务操作。画面底部是录制时添加的讲解层，未修改业务源码。

| 场景计时 | 画面与操作 | 讲解字幕 |
|---|---|---|
| 0.0–6.2 秒 | 库存异常诊断 · 实际操作录屏 | 合成库存 / Mock 模型 / 独立 Worker；展示权限、证据与失败处理 |
| 6.2–17.0 秒 | 01 / 先读取可追溯证据 | 案件来自服务端权限范围；模型只接收允许字段与合法引用 |
| 17.0–31.0 秒 | 02 / 真实入队，独立 Worker 执行 | 页面轮询数据库状态；结构化输出仍需通过引用与 Schema 校验 |
| 31.0–45.0 秒 | 03 / 证据不足时保留缺口 | 不编造根因；completed 表示流程完成，不表示库存已经修复 |
| 45.0–57.5 秒 | 04 / 未知引用被拒绝 | 任务失败并记录 invalid_provider_output；不会产生新的有效诊断 |
| 57.5–70.0 秒 | 05 / 切换只读角色，后端继续授权 | 可见案件 6 → 4；诊断/复检禁用，越范围案件接口返回 404 |
| 70.0–77.0 秒 | 权限、证据、任务恢复，是同一条执行边界 | 本片展示 Mock 功能路径；真实进程故障与旧结果隔离见验收测试 |

计时从首个页面载入后开始；视频包含很短的页面载入间隔。`assets/demo.srt` 是同一分镜文本的计时参考；画面已包含实际讲解字幕，不要求播放器加载侧字幕。无配音，可作为面试口头讲解底片。

使用独立 Compose 项目、新合成数据卷、Mock 和独立 Worker 录制。只捕获网页，不含浏览器账号、终端、桌面或原业务素材。第 3 张故障／模型缺证据与未知引用均为明确标注的 Mock 场景，不是对真实模型的错误统计。
