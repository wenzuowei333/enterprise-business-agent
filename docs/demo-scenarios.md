# 演示场景

所有场景使用合成库存，模型响应为 Mock。默认本机端口 18130；当前整理环境已有演示时可直接使用原演示，另建实例需覆盖端口。

| 场景 | 输入与操作 | 预期业务结果 |
|---|---|---|
| 正常诊断 | demo_admin → DEMO-CASE-001 → 正常结构化诊断 → 提交 | 任务完成；结果包含规则事实和合法引用；不改变库存数量 |
| 证据不足 | 同案 → 证据不足 → 提交 | 返回缺少上游凭证的缺口，零编造引用；completed 不等于问题解决 |
| 未知引用 | 同案 → 未知引用 → 提交 | 任务 failed，invalid_provider_output；不能生成新的有效诊断 |
| 只读角色 | 切换 demo_viewer，再选案件 | 案件从 6 变 4；诊断/复检禁用；越范围案件读取为 404 |
| 撤权/证据变化 | 运行对应 PostgreSQL 回归 | 调用前后复核，取消或拒绝旧结果；不靠界面按钮推断权限有效 |
| 中断与迟到回写 | 运行 SIGKILL/SIGSTOP 回归 | 新进程接管；恢复的旧进程不能覆盖新代次结果 |

密码：`LocalDemo-2026!`。正常、缺证据和未知引用可以依次运行；已有活动任务时会复用，不保证每次点击都新增任务。终态结果、任务失败和“库存已修复”是不同概念。

任务故障没有在主视频中伪装成可见 UI 操作；请运行 [测试入口](evaluation.md) 查看真实进程证据。录屏时间轴见 [demo-script.md](demo-script.md)。
